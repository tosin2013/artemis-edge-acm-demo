= Artemis Edge ACM Demo
:page-layout: home

== Overview

This demo showcases a federated AMQ Broker messaging architecture deployed across RHACM-managed Single Node OpenShift (SNO) edge clusters. Edge brokers use AMQP federation to route regional messages (`messages.NY.#`, `messages.NJ.#`, `messages.CT.#`) back to hub brokers with store-and-forward resilience.

=== Architecture

* *Hub Cluster* -- RHACM hub running ArgoCD, Keycloak OIDC, hub AMQ Brokers, Prometheus, and Grafana
* *Edge Clusters* -- SNO clusters (NY, NJ, and optionally CT). RHACM Governance (`edge-broker-policies`) installs the AMQ Broker operator and one `ActiveMQArtemis` per region after join
* *Messaging* -- AMQP federation from each SNO broker to hub-01 (`messages.NY.#`, `messages.NJ.#`, `messages.ALL.#`) over an AMQPS Route

=== Deployment Mode

ifdef::mode_multi_hub[]
You are running *Mode 2: Multi-Hub* with a Multicluster Global Hub, 2 regional hubs, and 6 SNO edge clusters.
endif::[]
ifndef::mode_multi_hub[]
You are running *Mode 1: Single Hub* with 1 RHACM hub and 3 SNO edge clusters.
endif::[]

=== Getting Started

Open the *Terminal 1* tab on the right and log in to your OpenShift cluster:

[source,bash,role=execute,subs="attributes+"]
----
{login_command}
----

Verify you are logged in:

[source,bash,role=execute]
----
oc whoami
----

You should see `{user}`. You now have read access to all cluster resources used in this demo.

TIP: Your credentials are `{user}` / `{password}`. The OpenShift Web Console is available at https://console-openshift-console.{openshift_cluster_ingress_domain}[Console ↗].
