= Module 0: Access Your Environment

== Objectives

* Log in to the OpenShift cluster from the terminal
* Verify access to all demo services
* Understand which credentials to use

== Log In to Your Cluster

Start by logging in to the OpenShift cluster. Run the following command in the Showroom terminal:

[source,bash,role=execute,subs="attributes+"]
----
{login_command}
----

Verify you are logged in:

[source,bash,role=execute]
----
oc whoami
----

You should see your username (e.g. `{user}`).

TIP: The Showroom terminal may also have cluster-admin access via a pre-configured service account. The `oc login` above ensures you are authenticated as your own user.

== Terminal home directory

The Showroom terminal image sets `lab-user` home in `/etc/passwd` to `/data`, which is not mounted. OpenJDK `user.home` follows passwd, so `export HOME` is not enough for Maven. Point the JVM and Maven repo at the writable PVC (`/home/lab-user`) before any `mvn` commands (optional Java build in xref:module-04.adoc[Module 4]):

[source,bash,role=execute]
----
export HOME=/home/lab-user
export MAVEN_USER_HOME=/home/lab-user/.m2
export JAVA_TOOL_OPTIONS="-Duser.home=/home/lab-user"
export MAVEN_OPTS="-Dmaven.repo.local=/home/lab-user/.m2/repository"
mkdir -p /home/lab-user/.m2
----

Optional: clone the demo repository if you want to inspect or compile the Java clients later. This is not required for the ACM hub and spoke exercises.

[source,bash]
----
git clone https://github.com/tosin2013/artemis-edge-acm-demo.git
cd artemis-edge-acm-demo
----

== Messaging Users (OIDC)

NOTE: This lab uses Keycloak for broker authentication as a self-contained lab convenience. In production, AMQ Broker supports direct Active Directory / LDAP authentication via `LDAPLoginModule` in the JAAS `login.config` — no Keycloak intermediary is required. The `LDAPLoginModule` configuration can be pushed to edge SNOs via the same ACM ConfigurationPolicy mechanism used for the broker CR. See the https://docs.redhat.com/en/documentation/red_hat_amq_broker/7.12/html/configuring_amq_broker/assembly-br-securing-brokers_configuring[AMQ Broker 7.12 LDAP integration docs] for a Microsoft Active Directory example.

== Namespaces

The demo uses the following namespaces:

* `artemis` -- AMQ Broker hub and edge instances
* `keycloak` -- Keycloak OIDC provider
* `open-cluster-management` -- RHACM hub
* `open-cluster-management-observability` -- MCO (Grafana, Thanos) — only if MCO is deployed
* `openshift-gitops` -- ArgoCD

Verify the ArgoCD application is healthy:

[source,bash,role=execute]
----
oc get application.argoproj.io -n openshift-gitops
----

You should see `field-content` with `Synced` and `Healthy` status.
