= Module 1: Verify Hub Cluster and RHACM

== Objectives

* Confirm the RHACM hub is healthy
* Verify ArgoCD Applications are synced
* Check operator subscriptions are installed

== Steps

=== 1. Verify RHACM MultiClusterHub

[source,bash,role=execute]
----
oc get multiclusterhub -A
----

The `status.phase` should be `Running`.

.Expected output
[source,text]
----
NAMESPACE                 NAME              STATUS    AGE    CURRENTVERSION   DESIREDVERSION   MESSAGE
open-cluster-management   multiclusterhub   Running   167m   2.17.1           2.17.1           All hub components ready.
----

=== 2. Check ArgoCD Applications

[source,bash,role=execute]
----
oc get application.argoproj.io -n openshift-gitops
----

All applications should show `Synced` and `Healthy`.

.Expected output
[source,text]
----
NAME            SYNC STATUS   HEALTH STATUS
field-content   Synced        Healthy
----

=== 3. Verify Operator Subscriptions

[source,bash,role=execute]
----
oc get sub -n artemis
oc get sub -n keycloak
----

Confirm `amq-broker-rhel8` and `keycloak-operator` subscriptions exist. The output shows the `PACKAGE`, `SOURCE`, and `CHANNEL` columns.

.Expected output
[source,text]
----
NAME               PACKAGE            SOURCE             CHANNEL
amq-broker-rhel8   amq-broker-rhel8   redhat-operators   7.12.x

NAME                PACKAGE             SOURCE                CHANNEL
keycloak-operator   keycloak-operator   community-operators   fast
----

=== 4. Check Managed Clusters

[source,bash,role=execute]
----
oc get managedclusters
----

ifndef::mode_multi_hub[]
NOTE: In Mode 1 (single-hub), you will only see `local-cluster`. Edge SNO clusters are provisioned in Module 2 for multi-cluster deployments.

.Expected output
[source,text]
----
NAME            HUB ACCEPTED   MANAGED CLUSTER URLS                                           JOINED   AVAILABLE   AGE
local-cluster   true           https://api.hub.<guid>.gcp.redhatworkshops.io:6443   True     True        ...
----
endif::[]
ifdef::mode_multi_hub[]
You should see 3 SNO edge clusters (or 6 in Mode 2) with `ManagedClusterConditionAvailable=True`.
endif::[]

TIP: All four checks passing confirms the hub cluster is healthy and ready for the messaging modules. If any step shows unexpected output, verify the ArgoCD `field-content` application is `Synced` and `Healthy` before proceeding.
