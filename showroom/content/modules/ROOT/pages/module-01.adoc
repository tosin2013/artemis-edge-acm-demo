== Objectives

* Confirm the RHACM hub is healthy
* Verify ArgoCD Applications are synced
* Check operator subscriptions are installed

ifdef::mode_multi_hub[]
This terminal is **regional ACM east**, not Global Hub. Confirm `local-cluster` is this ACM hub. SNOs do not exist until xref:module-02.adoc[Module 2].

.Mode 2 control plane — you are on regional ACM east
image::mode2-control-plane.png[Mode 2 three-tier control plane. You are here is marked on ACM east. Managed clusters on this hub are only local-cluster until Module 2.,link=self,window=blank,width=800]
endif::[]

== Steps

=== 1. Verify RHACM MultiClusterHub

[source,bash,role=execute]
----
oc get multiclusterhub -A
----

The `status.phase` should be `Running`.

.Expected output
[source,text]
----
NAMESPACE                 NAME              STATUS    AGE    CURRENTVERSION   DESIREDVERSION   MESSAGE
open-cluster-management   multiclusterhub   Running   167m   2.17.1           2.17.1           All hub components ready.
----

=== 2. Check ArgoCD Applications

[source,bash,role=execute]
----
oc get application.argoproj.io -n openshift-gitops
----

All applications should show `Synced`. `field-content` may remain `Progressing` (ApplicationSet with no children). Do not bind `ztp-policies` to "fix" that.

.Expected output
[source,text]
----
NAME            SYNC STATUS   HEALTH STATUS
field-content   Synced        Healthy
----

=== 3. Verify Operator Subscriptions

[source,bash,role=execute]
----
oc get sub -n artemis
oc get sub -n keycloak
----

Confirm `amq-broker-rhel8` and `rhbk-operator` (Red Hat Build of Keycloak) subscriptions exist. The output shows the `PACKAGE`, `SOURCE`, and `CHANNEL` columns.

ifndef::mode_multi_hub[]
.Expected output
[source,text]
----
NAME               PACKAGE            SOURCE             CHANNEL
amq-broker-rhel8   amq-broker-rhel8   redhat-operators   7.12.x

NAME              PACKAGE        SOURCE             CHANNEL
rhbk-operator     rhbk-operator  redhat-operators   stable-v26
----
endif::[]

ifdef::mode_multi_hub[]
.Expected output
[source,text]
----
NAME               PACKAGE            SOURCE             CHANNEL
amq-broker-rhel8   amq-broker-rhel8   redhat-operators   7.12.x

NAME              PACKAGE        SOURCE             CHANNEL
rhbk-operator     rhbk-operator  redhat-operators   stable-v26
----

NOTE: These subscriptions are created by the `field-content` ArgoCD Application on this regional hub. If field-content sync has not yet completed, the `artemis` and `keycloak` namespaces may not exist yet. Check `oc get application.argoproj.io field-content -n openshift-gitops` — it should be `Synced` before these subscriptions appear.
endif::[]

=== 4. Check Managed Clusters

[source,bash,role=execute]
----
oc get managedclusters
----

ifndef::mode_multi_hub[]
You always see `local-cluster` (the hub). If SNOs were provisioned (this catalog item, or xref:module-02.adoc[Module 2]), you also see `sno-edge-01` and `sno-edge-02` with `JOINED=True` and `AVAILABLE=True`.

.Expected output (Mode 1 after SNOs join)
[source,text]
----
NAME            HUB ACCEPTED   MANAGED CLUSTER URLS                                           JOINED   AVAILABLE
local-cluster   true           https://api.hub.<guid>.gcp.redhatworkshops.io:6443        True     True
sno-edge-01     true           https://api.sno-edge-01.<guid>.gcp.redhatworkshops.io:6443 True     True
sno-edge-02     true           https://api.sno-edge-02.<guid>.gcp.redhatworkshops.io:6443 True     True
----
endif::[]
ifdef::mode_multi_hub[]
Managed clusters: **only `local-cluster` until Module 2**. `local-cluster` is this regional ACM hub. After Module 2, `sno-edge-01` and `sno-edge-02` join *this* hub. They never appear as direct managed clusters of Global Hub.

.Expected output (before Module 2)
[source,text]
----
NAME            HUB ACCEPTED   MANAGED CLUSTER URLS                                      JOINED   AVAILABLE
local-cluster   true           https://api.hub.<guid>.gcp.redhatworkshops.io:6443    True     True
----
endif::[]

TIP: `field-content` in ArgoCD may stay `Progressing` because ApplicationSet `artemis-edge-workloads` has no child apps. That is expected — AMQ on SNOs is delivered by ACM policies in `edge-broker-policies`, not by ArgoCD apps on the spokes.
