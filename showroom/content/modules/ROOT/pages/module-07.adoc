= Module 7: Global Hub Compliance Grafana (Mode 2 Only)

== Objectives

* Access Multicluster Global Hub **compliance** Grafana (PostgreSQL) — not AMQ metrics
* View policy compliance and inventory across the three regional ACM hubs
* Confirm sites you added in Module 2 appear under the east managed hub

NOTE: This module applies only to Mode 2. If you are running Mode 1, skip to xref:module-08.adoc[Module 8].

IMPORTANT: Global Hub Grafana is **compliance only**. It does not merge `artemis_*`. Fleet AMQ Grafana is xref:module-08.adoc[Module 8] (regional MCO + extra Thanos Query on Global Hub).

== Steps

=== 0. Verify All Regional Hubs Are Visible

Before viewing compliance dashboards, confirm the Global Hub has inventory of all three regional hubs:

[source,bash]
----
oc get managedclusters
----

.Expected output
[source,text]
----
NAME            HUB ACCEPTED   MANAGED CLUSTER URLS                                        JOINED   AVAILABLE   AGE
cen-ctbz4       true           https://api.hub-central.ctbz4.gcp.redhatworkshops.io:6443   True     True        11m
east-ctbz4      true           https://api.hub-east.ctbz4.gcp.redhatworkshops.io:6443      True     True        11m
local-cluster   true           https://api.hub.ctbz4.gcp.redhatworkshops.io:6443           True     True        17h
west-ctbz4      true           https://api.hub-west.ctbz4.gcp.redhatworkshops.io:6443      True     True        11m
----

All three regional hubs (`east`, `cen`, `west`) must show `JOINED=True` and `AVAILABLE=True`. If a hub is missing, the compliance dashboard will not show its policies. See xref:hub-of-hubs-verify.adoc[Facilitator: Verify Hub-of-Hubs] for troubleshooting.

=== 1. Access Global Hub Grafana

From a kubeconfig for the **Global Hub** (facilitator), not this regional hub:

[source,bash]
----
oc get route -n open-cluster-management -l app=multicluster-global-hub
----

=== 2. View Fleet Compliance

In the Grafana dashboard:

* Select the *Global Hub - Policy Compliance* dashboard
* Observe compliance across regional hubs east, central, and west
* After Module 2, the NY/NJ SNOs appear in inventory *under* the east managed hub — they are not Global Hub managed clusters

=== 3. Cross-Hub Cluster Inventory

[source,bash]
----
oc get managedclusterset -A
oc get placement -A
----

The Global Hub aggregates cluster inventory from the three regional hubs. Sites never talk to Global Hub.

=== 4. Verify there is no AMQ broker on Global Hub

[source,bash]
----
oc get activemqartemis -A
----

Expected: no `hub-01-broker` (or any AMQ CR) on Global Hub. The AMQ hub for east is on *this* regional cluster (`oc get activemqartemis -n artemis` here).
