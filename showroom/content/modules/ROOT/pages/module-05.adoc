= Module 5: Produce and Consume Messages

== Objectives

* Send messages from SNO edge brokers using regional addresses
* Consume those messages at hub-01 (federation)
* Confirm hub-colocated `spoke-*` URLs are not this exercise

ifdef::mode_multi_hub[]
Hub-01 in these steps is the **AMQ hub on this regional ACM hub**, not Global Hub. `messages.NY.5604` should appear on hub-01; `messages.NY.5603` must not.
endif::[]

== Steps

=== 1. Start a Consumer on the Hub

IMPORTANT: Start the consumer *before* producing messages. Topic (multicast) subscriptions only receive messages sent after the subscription is created.

Open a terminal and run:

[source,bash,role=execute]
----
oc -n artemis run consumer -ti \
  --image=registry.redhat.io/amq7/amq-broker-rhel8:7.12 \
  --rm=true --restart=Never -- /bin/bash
----

Inside the container:

[source,bash,subs="attributes+"]
----
/opt/amq/bin/artemis consumer \
  --url=amqp://hub-01-broker-amqp-acceptor-0-svc.artemis.svc.cluster.local:5672 \
  --protocol=AMQP --user={consumer_user} --password={consumer_password} \
  --destination=topic://messages.NY.test --message-count=5 --receive-timeout=60000 --verbose
----

TIP: If `{consumer_user}`/`{consumer_password}` fails with a SASL authentication error, use `admin`/`admin` instead.

Leave this consumer running and open a *second terminal* for the next step. After the NY producer finishes, the consumer prints five `Received` lines and `Consumed: 5 messages`. JMS Message IDs and elapsed time differ every run.

.Expected output (hub consumer, after NY produce)
[source,text]
----
Consumer messages.NY.test, thread=0 Received hello from NY SNO
Consumer messages.NY.test, thread=0 Received hello from NY SNO
Consumer messages.NY.test, thread=0 Received hello from NY SNO
Consumer messages.NY.test, thread=0 Received hello from NY SNO
Consumer messages.NY.test, thread=0 Received hello from NY SNO
Consumer messages.NY.test, thread=0 Consumed: 5 messages
----

.CLI — hub consumer received five NY messages (not Grafana)
image::m5-hub-consumer-ny.png[CLI output of artemis consumer on topic messages.NY.test showing five Received hello from NY SNO lines and Consumed: 5 messages.,link=self,window=blank,width=800]

=== 2. Produce from the NY SNO

Use the sno-edge-01 AMQPS Route. SNO brokers use `admin` / `admin`.

[source,bash,subs="attributes+"]
----
oc -n artemis run producer-ny -ti \
  --image=registry.redhat.io/amq7/amq-broker-rhel8:7.12 \
  --rm=true --restart=Never -- /opt/amq/bin/artemis producer \
  --url='amqps://spoke-01-broker-amqps-acceptor-0-svc-rte-artemis.apps.sno-edge-01.{guid}.gcp.redhatworkshops.io:443?sslEnabled=true&transport.trustAll=true&transport.verifyHost=false&useTopologyForLoadBalancing=false' \
  --protocol=AMQP --user=admin --password=admin \
  --message-count=5 --message='hello from NY SNO' \
  --destination=topic://messages.NY.test --verbose
----

.Expected output
[source,text]
----
Producer messages.NY.test, thread=0 Sent: hello from NY SNO
Producer messages.NY.test, thread=0 Sent: hello from NY SNO
Producer messages.NY.test, thread=0 Sent: hello from NY SNO
Producer messages.NY.test, thread=0 Sent: hello from NY SNO
Producer messages.NY.test, thread=0 Sent: hello from NY SNO
Producer messages.NY.test, thread=0 Produced: 5 messages
----

.CLI — NY SNO producer (not the ACM console)
image::m5-producer-ny.png[CLI output of artemis producer to the NY SNO AMQPS Route. Five Sent hello from NY SNO lines and Produced: 5 messages.,link=self,window=blank,width=800]

The hub consumer in step 1 should then show the five `messages.NY.test` messages (see that step's expected output). Elapsed-time lines differ every run.

=== 3. Produce from the NJ SNO

[source,bash,subs="attributes+"]
----
oc -n artemis run producer-nj -ti \
  --image=registry.redhat.io/amq7/amq-broker-rhel8:7.12 \
  --rm=true --restart=Never -- /opt/amq/bin/artemis producer \
  --url='amqps://spoke-02-broker-amqps-acceptor-0-svc-rte-artemis.apps.sno-edge-02.{guid}.gcp.redhatworkshops.io:443?sslEnabled=true&transport.trustAll=true&transport.verifyHost=false&useTopologyForLoadBalancing=false' \
  --protocol=AMQP --user=admin --password=admin \
  --message-count=5 --message='hello from NJ SNO' \
  --destination=topic://messages.NJ.test --verbose
----

.Expected output

----
Producer messages.NJ.test, thread=0 Sent: hello from NJ SNO
Producer messages.NJ.test, thread=0 Sent: hello from NJ SNO
Producer messages.NJ.test, thread=0 Sent: hello from NJ SNO

Start a hub consumer on `topic://messages.NJ.test` first if you want to see these arrive:

[source,bash,subs="attributes+"]
----
/opt/amq/bin/artemis consumer \
  --url=amqp://hub-01-broker-amqp-acceptor-0-svc.artemis.svc.cluster.local:5672 \
  --protocol=AMQP --user={consumer_user} --password={consumer_password} \
  --destination=topic://messages.NJ.test --message-count=5 --receive-timeout=60000 --verbose
----

.Expected output (hub consumer, after NJ produce)
[source,text]
----
Consumer messages.NJ.test, thread=0 Received hello from NJ SNO
Consumer messages.NJ.test, thread=0 Received hello from NJ SNO
Consumer messages.NJ.test, thread=0 Received hello from NJ SNO

The SNO remote address policy *pushes* `messages.{region}.#` to hub-01. `messages.ALL.#` is pulled from the hub onto the SNO, not the reverse.
